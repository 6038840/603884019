# 供应管理二维码原型 v3.3 使用说明

本版用于确认企业供应管理的商品二维码功能。列表按截图还原，新增单个二维码和多商品批量下载，保留原有编辑、只读详情和标签管理入口。v3.2 文件未修改。

## 打开原型

直接打开 `供应管理_二维码原型_v3.3.html`。所有页面、样式和交互都包含在这个文件中，可单独转发，无需联网或安装依赖。

`index.html` 是分文件开发版入口，需要保留同目录的 JS、CSS 和 vendor 文件。两个入口的功能相同，使用独立于 v3.2 的演示数据。

## 二维码操作

- 列表操作列【生成二维码】：预览二维码，下载 PNG，复制商品链接或打开原有商品详情。
- 【导出】左侧【批量生成二维码】：按钮始终可点击；未勾选商品时提示“请先选择商品”，勾选后进入批量生成弹窗。支持多选、全选当前筛选结果及保留其他筛选结果的已选商品。按钮旁显示已选数量。
- 批量弹窗逐项列出可生成情况；确认后生成 ZIP，一个商品一张 PNG。不符合条件的商品先明确说明，不加入压缩包。
- 生成中可取消，生成失败可重试。下载前重新检查商品状态。

不增加统计卡片、二维码管理页、历史记录、格式设置或二维码专用详情页。产品库配置和审批规则不增加新设计。

原有基本功能沿用 v3.2 的原型范围，导入、上传、联系供应商等不连接现有系统后端。本次 PNG 和 ZIP 为真实下载文件；列表导出提供 CSV 演示文件。

商城可访问范围沿用 v3.2：已上架且可供。二维码生成还需供应审核通过，产品库标签审批状态不影响生成。编辑商品提交审核后，待审核期间不可新生成二维码。

已上架商品的变更审核仍沿用现有发布流程：如果商城继续展示该商品，已下载的二维码继续指向同一商品，不因变更待审核而额外下架商品。

生成、复制和下载不修改商品资料、供应审核或标签状态。二维码不可用时，悬停或通过键盘聚焦可查看原因。商品下架、停供或删除后，原二维码显示商品不可查看，不跳转到其他商品。

## 扫码与实现边界

二维码内容为公开商品详情链接：`当前入口文件?product=商品ID#mall-detail`。同一入口、同一商品重复生成时链接不变，商品名称、价格或标签更新不改变商品身份。详情沿用原型已有页面，不进入企业后台。

本地文件生成的二维码指向电脑的本地 HTML，手机无法访问电脑的 `file://` 路径。手机扫码联调需要把单文件 HTML 或完整分文件版部署到手机可访问的 HTTPS 地址，再生成二维码。部署后默认自动使用该入口地址；本版没有创建现有系统的真实商品详情地址。

演示修改只保存在当前浏览器，其他设备不共享。正式接入时，公开详情和商品状态从现有后端取数，生成服务核对商品所属企业及可访问状态；不使用后台链接、登录信息或临时附件地址作为码内链接。

本版无需第三方二维码服务，使用本地 QR Code Generator 2.0.4 和 JSZip 3.10.1。图片为 512×512 黑白 PNG，保留四个模块以上的空白边缘。文件名为【商品ID_供应名称.png】，一个压缩包内各商品文件不重复。

研发接入时替换 `qrProductURL()` 和详情的取数、可访问判断即可。`window.QR_PUBLIC_BASE_URL` 可指定部署后的同结构公开入口。

## 源文件

- `index.html`、`app.js`、`styles.css`：延续 v3.2 的页面与基础交互。
- `qr.js`、`qr.css`：本次列表和二维码交互。
- `vendor/`：二维码、压缩库及许可证。
- `供应管理_二维码原型_v3.3.html`：完整单文件交付版。
